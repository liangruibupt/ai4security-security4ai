# 可复用设计模式

从各篇深读里提炼的模式，按用途分组。每条给出一句话做法和出处，细节和代码位置见原文的「可复用模式」一节。

## 一、让判定可信：决策交给代码，大模型只写句子

| 模式 | 做法 | 出处 |
|---|---|---|
| 派生状态全量重算 | 事件只存证据编号，真实性和严重度每次用纯函数从全部证据重算，规则修正后旧事件也会更新 | [02 判定](../ai4security/01-security-radar/02-decisions-in-code.md#可复用模式) |
| 并查集计算独立来源 | 同机构、互相引用、引用同一推文、标题相似度 ≥ 0.85 的来源合为一组，按组计数，转载不抬高可信度 | 同上 |
| 紧急度 = 影响 × 证据新鲜度 | P0 须同时满足影响规则和 72 小时窗口，时间取证据发布时间而不是处理时间 | 同上 |
| 逐句引用 + 代码校验 | 大模型每句必须引用条目编号，代码检查引用存在、数字出现在原文；不合格的句子标为未证实，不删除 | 同上 |
| 修复版本逐字取自证据 | 修复版本号从公告原文抽取，不靠模型记忆 | [PHP2Shell 案例](../ai4security/02-php2shell-case/README.md#可复用模式) |

## 二、诚实地表达「不知道」

| 模式 | 做法 | 出处 |
|---|---|---|
| 0 条结果即错误 | 信源 HTTP 200 但解析出 0 条，记为失败并保留旧游标，不当作「没有新闻」 | [01 架构](../ai4security/01-security-radar/01-architecture-and-guardrails.md#可复用模式) |
| 版本无法比较就明说 | 部分版本钉死或未登记的分支返回 `unknown`，交给人工或 AI 评审，不猜 | [03 响应](../ai4security/01-security-radar/03-respond-and-mitigate.md#可复用模式) |
| 扫描盲区记为无法判断 | Inspector ScanSbom 不判运行时版本，结果记「无法判断」而不是「干净」 | [PHP2Shell 案例](../ai4security/02-php2shell-case/README.md#可复用模式) |

## 三、自动化的边界：先观察，人来拦截

| 模式 | 做法 | 出处 |
|---|---|---|
| 纯决策函数 + 薄执行器 | 计划由无副作用函数生成并可单测，执行层只做 API 调用 | [03 响应](../ai4security/01-security-radar/03-respond-and-mitigate.md#可复用模式) |
| 非阻断优先，阻断由人提升 | WAF 规则先 Count、DNS Firewall 先 ALERT，切换到拦截须由人执行并记录是谁 | 同上 |
| 只写自己创建的资源 | IAM 按名称前缀限定，代码也只操作自己的资源，从不删除规则 | 同上 |
| 补丁只在上下文全部匹配时应用 | 补丁 hunk 与目标文件不一致就跳过，不强行应用 | [PHP2Shell 案例](../ai4security/02-php2shell-case/README.md#可复用模式) |

## 四、成本与可靠性

| 模式 | 做法 | 出处 |
|---|---|---|
| 按结果触发付费操作 | 只为已成功提交的 finding 发起扫描，每个环境 24 小时最多一次 | [03 响应](../ai4security/01-security-radar/03-respond-and-mitigate.md#可复用模式) |
| 内容哈希做幂等令牌 | 令牌 = 稳定标识 + 去掉时间戳后的内容哈希：同一内容重试幂等，内容改了就是新请求 | 同上 |
| 付费或不稳定工位不阻塞发布 | 状态机捕获 Analyze / Respond / Mitigate 的失败，发布照常进行 | [01 架构](../ai4security/01-security-radar/01-architecture-and-guardrails.md#可复用模式) |

## 五、让安全约束可测试

| 模式 | 做法 | 出处 |
|---|---|---|
| IAM 与 SDK 调用双向相等 | 用 `ast` 静态提取代码里的 boto3 调用，测试它与 IAM 授权动作完全一致 | [01 架构](../ai4security/01-security-radar/01-architecture-and-guardrails.md#可复用模式) |
| 变异注册表 | 为每道防护登记一个「删掉它」的变异，证明对应测试会失败 | 同上 |
| 先验证门禁再上传内容 | 部署时先确认匿名请求返回 401，再上传站点 | 同上 |
| stage 派生资源名 | 所有资源名带 stage，销毁脚本拒绝空 stage | 同上 |
